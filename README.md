# クラスパーカー デザインメーカー

黄色のパーカー（正面・背面）に、画像を重ねてデザインを試せる静的サイトです。
サーバーやFirebaseは使わず、HTML / CSS / JavaScript だけで動きます。

## 使い方

1. 画面下のタブ「＋ 画像を追加」から画像を選ぶ（複数選択可）
2. 並んだサムネイルをタップすると、パーカーに重なる（「追加する面」で正面/背面を選べる）
3. ドラッグで移動、右下の丸いハンドルで拡大縮小・回転、左上の×で削除
4. 右（スマホでは下）のパネルで、色の変更・背景の透明化・前後の入れ替え・複製
5. 「PNGで保存」で完成イメージを画像としてダウンロード

アップロードした画像はブラウザの中だけで処理され、どこにも送信されません。
ページを再読み込みすると内容は消えるので、残したいときは PNG で保存してください。

## ファイル構成

- `index.html` / `style.css` / `app.js` … サイト本体
- `images/hoodie.jpg` … パーカーの画像

## GitHub Pages で公開する

リポジトリの Settings → Pages → Build and deployment で、
Source を「Deploy from a branch」、Branch を公開したいブランチの `/ (root)` にして Save。

## ローカルで試す

`index.html` をそのまま開くと PNG 保存が使えないことがあります。次のようにして開いてください。

```
python3 -m http.server 8000
# http://localhost:8000/ を開く
```
