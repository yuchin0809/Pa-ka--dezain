# 1-Iクラスパーカデザインメーカー

黄色のパーカー（正面・背面）に、画像・文字・手書きの線・スタンプを重ねてデザインを試せる静的サイトです。
サーバーやFirebaseは使わず、HTML / CSS / JavaScript だけで動きます。

## 使い方

画面下のタブで、追加するものを切り替えます。

### 画像
1. 「＋ 画像を追加」から画像を選ぶ（複数選択可）
2. 並んだサムネイルをタップすると、パーカーに重なる（上の「追加する面」で正面/背面を選べる）
3. 重ねた画像を選ぶと、右（スマホ・iPad縦では下）のパネルで次のことができる
   - **一色にする**: ロゴ・イラストの形を好きな色で塗る
   - **色味を変える**: 写真やカラー画像の色合い・鮮やかさ・明るさを変える
   - **特定の色を置き換える**: 画像をタップして選んだ色だけを、別の色に置き換える
   - **背景を透明にする**: 白でも他の色でも、タップした色を透明にする
   - **トリミング**: 四角い枠で残す範囲を選ぶ

### テキスト
1. 「＋ テキストを追加」を押す
2. パネルで、文字の入力・フォント・色・太字・縦書き・縁取り・行の揃え・アーチ（カーブ）・影を変える
   - フォントは Google Fonts の日本語フォント12種類（ゴシック、明朝、丸ゴシック、手書き風、極太 など）

### 手書き
指やタッチペン、マウスで、パーカーに直接描けます。ツールは次のとおりです。
- ペン（フリーハンド） / 直線 / 四角 / 丸 / 消しゴム（線を部分的に消せる） / 選択
- 色と線の太さ（消しゴムは大きさ）を選べる。四角・丸は「塗りつぶし」もできる
- 直線は水平・垂直に近いと自動でまっすぐになる。Shift を押しながら四角・丸なら正方形・正円、直線なら45°刻み
- 描いた線は、「選択」ツール（または他のタブ）でタップすると、画像と同じように移動・拡大縮小・回転・色・線の太さ・塗りの変更ができる
- 塗りつぶした図形は、消しゴムでなぞると丸ごと消える

### スタンプ
- 図形（ハート・星・王冠・吹き出し・矢印・花など24種類。色を自由に変えられる）
- 絵文字（テキストとして追加されるので、大きさや影も変えられる）

### 色の選びかた（共通）
- よく使う色のほか、「その他の色」を押すと、色合い・鮮やかさ・明るさのスライダーで好きな色を作れる
- 「その他の色」で選んだ色は、「最近使った色」にならぶ（この端末に覚えておく）

### 共通の操作
- ドラッグで移動、右下の丸いハンドルで拡大縮小・回転、左上の×で削除
- 回転は 0°・90°・180° に近づくとぴたっと吸着し、ガイド線が出ます（パネルの「水平にする」で 0° に戻せます）
- 移動中は、パーカーの中心線や他のデザインの中心・端に近づくと吸着し、ガイド線が出ます
- Alt キー（パソコン）を押しながら操作すると、吸着を一時的に切れます
- パネルで、前後の入れ替え・複製・削除
- ↶ ↷ で、どの操作も元に戻す・やり直しができる（Ctrl+Z / Ctrl+Shift+Z も可）

### 保存・共有
- 「保存」「共有」を押すと、完成画像（PNG）の**共有画面**が開きます
  - iPhone / iPad: 共有画面で「**画像を保存**」を選ぶと、写真アプリに入ります。LINE などへ送るときは「共有」から
  - 共有画面を開けない環境（一部のパソコンなど）では、画像ファイルのダウンロードになります
- 「新しく始める」で、いまのデザインと追加した画像をすべて消して最初から始められます

### 自動保存
作業は自動でこの端末のブラウザの中に保存され、次に開いたとき続きから作れます。
他の端末や他の人とは共有されません。

## ホーム画面に追加して使う

- iPhone / iPad: Safari で開き、共有ボタン →「ホーム画面に追加」
- Android: Chrome のメニュー →「ホーム画面に追加」（または「アプリをインストール」）

一度開くと必要なファイルが端末に保存され、ホーム画面のアイコンからオフラインでも起動できます。
フォントも、一度使った文字ぶんは端末に保存されます（初めて使う文字は、ネットにつながっている必要があります）。
サイトを更新したときは、ネットにつながった状態で開けば自動で新しくなります。

## ファイル構成

- `index.html` / `style.css` / `app.js` … サイト本体
- `images/hoodie.jpg` … パーカーの画像
- `manifest.webmanifest` / `sw.js` / `icons/` … ホーム画面追加・オフライン用

### サイトを更新するときの注意
`sw.js` の先頭にある `CACHE`（例: `parka-v5`）の名前を、ファイルを変えるたびに変えてください。
名前を変えると、新しいファイルが裏で保存され、利用者が次に開いたときから新しくなります
（変えないと、端末に保存された古いファイルが使われ続けます）。

## GitHub Pages で公開する

リポジトリの Settings → Pages → Build and deployment で、
Source を「Deploy from a branch」、Branch を公開したいブランチの `/ (root)` にして Save。

## ローカルで試す

`index.html` をそのまま開くと PNG 保存が使えないことがあります。次のようにして開いてください。

```
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## プライバシー

アップロードした画像や作ったデザインは、この端末のブラウザの中だけで処理・保存され、サーバーには送信されません。
ただし、テキストのフォントは Google Fonts から読み込むため、利用時に Google のサーバーへアクセスします。
